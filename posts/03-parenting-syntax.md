Oggi, Lorenzo, è il tuo compleanno.

Sono dieci anni che sono padre, e ho scritto qualche riga di codice pensando a te e Tommaso.  
Questo per ricordarmi ogni giorno come vorrei essere vostro padre.

### 01 — Love

```python
def love(child, unconditionally=True):
    child.loved = bool(unconditionally)

for child in children:
    love(child)
```

Amali entrambi senza condizioni. Anche quando è difficile. Soprattutto quando è difficile.

---

### 02 — Presence

```python
while child.needs_help():
    parent.stay(close=True)
```

Quando hanno bisogno di te, resta.  
Anche quando non sai bene cosa fare.

---

### 03 — Respect

```python
def respect(other):
    treat(other, as_equal=True)

respect(child)
```

Trattali con rispetto.  
I bambini sono persone, con la loro dignità, il loro carattere e il loro mondo.

---

### 04 — Apology

```python
if parent.is_wrong():
    parent.say("sorry")
```

Quando sbagli, chiedi scusa.  
Essere loro padre non significa avere sempre ragione.

---

### 05 — Patience

```python
while not child.has_learned():
    parent.wait()
```

Dagli il loro tempo.  
Non devono imparare quando sei pronto tu.

---

### 06 — Example

```python
parent.do("kindness")
child.copy("kindness")
```

Se vuoi insegnargli la gentilezza, comincia da come tratti loro e gli altri.

---

### 07 — Listening

```python
voice = child.speak()
listen(voice, deeply=True)
```

Quando ti parlano, ascoltali davvero.

---

### 08 — Growth

```python
def grow(child, fuel="trust"):
    child.feed(fuel)

grow(child)
```

Fagli sentire che credi in loro.  
Soprattutto quando fanno fatica a crederci da soli.

---

### 09 — Emotion

```python
signal = child.emotion()

if signal == "cry":
    parent.hold(child)
elif signal == "laugh":
    parent.laugh_with(child)
else:
    parent.stay(attuned=True)
```

Se piangono, stringili.  
Se ridono, ridi con loro.  
E quando non capisci cosa sentono, resta vicino.

---

### 10 — Boundaries

```python
def set_limits(home, rules, tone="kind"):
    home.rules = {rule: tone for rule in rules}

set_limits(home, ["screen", "sleep", "safety"])
```

Metti dei limiti, certo.  
Ma fallo con calma, rispetto e gentilezza.

---

### 11 — Curiosity

```python
answers = {}

for question in child.questions():
    answers[question] = answer(question, honestly=True)
```

Prendi sul serio le loro domande, anche quelle che ti spiazzano.  
E se non sai la risposta, di' semplicemente che non la sai.

---

### 12 — Independence

```python
if child.is_ready():
    parent.release_control(keep_link=True)
```

Quando saranno pronti, lasciali andare per la loro strada.  
Ma non lasciare mai che il legame che vi unisce si indebolisca.

---

### 13 — Forgiveness

```python
def forgive(who):
    heart.open_to(who)

forgive(child)
forgive(parent)
```

Perdonali quando sbagliano.  
E prova a perdonarti quando a sbagliare sei tu.

---

### 14 — Play

```python
while together():
    play(pick_game())
```

Gioca con loro finché te lo chiedono.  
Un giorno, probabilmente, smetteranno di farlo.

---

### 15 — Gratitude

```python
for moment in childhood:
    parent.thank(moment)
```

Non dare per scontata la loro infanzia.  
Passa molto più in fretta di quanto sembra.

---

### 16 — Honesty

```python
truth = make_truth(gently=True)
parent.say(truth)
```

Di' loro sempre la verità.  
Ma ricordati che si può essere sinceri senza smettere di essere gentili.

### 17 — Legacy

```python
values = {
    "kindness": True,
    "courage": True,
    "wonder": True,
}

save(values, to="next_generation")
```

Più delle cose che lascerai, conta il modo in cui avrai insegnato loro a stare al mondo.

### 18 — Calm

```python
if anger.rises():
    parent.pause()
    parent.breathe()
```

Quando senti salire la rabbia, fermati un attimo.  
Fai un bel respiro.

---

### 19 — Wonder

```python
for discovery in child.discovers():
    parent.learn_from(discovery)
```

Guarda il mondo anche attraverso i loro occhi.  
Cerca sempre di ricordare quel qualcosa che, crescendo, hai dimenticato.
