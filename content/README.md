# Localized page content

Long-form page content lives here, separated by language.

- `content/it/about.md`
- `content/en/about.md`
- `content/it/semantic_map.md`
- `content/en/semantic_map.md`

Keep the same filename in both language folders. If a localized file is missing, the application falls back to Italian.

Posts are intentionally kept under `posts/it/` and `posts/en/`.
